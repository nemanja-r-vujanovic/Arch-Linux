Super + Enter            = Open alacritty
Ctrl + +                 = Increase font in alacritty
Ctrl + -                 = Decrease font in alacritty

Super + D                = Open dmenu
Super + 2                = New workspace
Super + Left             = Switch to left window
Super + Right            = Switch to right window

Alt + F4                 = Close app
Ctrl + Q                 = Close pcmanfm

Super + Shift + Q        = Close alacritty
Super + Shift + Left     = Move window to left
Super + Shift + Right    = Move window to right
Super + Shift + Up       = Move window to top
Super + Shift + Down     = Move window to bottom
Super + Shift + 2        = Move window to workspace 2
Super + Shift + Space    = Toggle tiling
Super + Shift + R        = Restart i3
Super + Shift + C        = Reload configs

Ctrl + Super + F         = Maximize window
Ctrl + Super + S         = Minimize window
Ctrl + Super + W         = Move window to top half
Ctrl + Super + X         = Move window to bottom half
Ctrl + Super + A         = Move window to left half
Ctrl + Super + D         = Move window to right half
Ctrl + Super + Q         = Move window to top-left corner
Ctrl + Super + E         = Move window to top-right corner
Ctrl + Super + Y         = Move window to bottom-left corner
Ctrl + Super + C         = Move window to bottom-right corner

Super + F1               = Mute volume
Super + F2               = Decrease volume
Super + F3               = Increase volume

Super + T                = Toggle picom (transparent alacritty)
Super + C                = Start chromium (standard)
Super + I                = Start chromium (incognito)
Super + B                = Start chromium (sandboxed)
Super + P                = Start pcmanfm (file manager)
Super + Print            = Start scrot (screenshot)
Super + Shift + P        = Start autorandr (projection)
Ctrl + Super + Backspace = Start poweroff (shutdown)
